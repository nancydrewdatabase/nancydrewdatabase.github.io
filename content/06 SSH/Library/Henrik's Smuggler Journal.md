## Text

###  <u>Number Stations</u>

2050 Hz transmits a series of 5 digits in Spanish with each transmission starting with 'Attencion, attencion.'

- Uno (oo-no) = 1
- Dos (dohs) = 2
- Tres (trays) = 3
- Cuatro (cwah-tro) = 4
- Cinco (seen-co) = 5
- Seis (sehs) =6
- Siete (see-eh-tay) = 7
- Ocho (oh-cho) = 8
- Nueve (new-eh-bay) = 9

### DECODING THE <u> NUMBERS </u>

Write down the last 3 digits of the series and add a zero to it to get a 4-digit number. Hold each of the original 5 digits and add the sum to the 4 digit number from the first step. This is the station that the smugglers will take messages on

#### EXAMPLE

if the station number gives '5 6 1 2 3' then the smuggler station is 1247:
1. Put a zero at the end of the last 3 digits (1230)
2. Add all of the digits in the series (5 + 6 + 1 + 2 + 3 = 17)
3. Add the number from step 1 to the number from step 2 (1230 + 17 = 1247)

- 66913 = 9155
- 48281 = 2833
- 81437 = 4393

### <u> Smuggler Stations </u>

Password is the Nahuatl word for 'snake'. Enter it in Morse code and they'll confirm by voice. Then send a code word.

- LECHE - Send the item immediately; the coast is clear.
- MUJER - Meet me at the rendezvous point
- SUENO - Don't send the item; the coast is not clear
- VACAS - Payment has been sent
