## Prerequisites
* Talk to all suspects
	* [[Dexter Egan]]
	* [[Jacques Brunais]]
	* [[Professor Hotchkiss]]
	* [[Lisa Ostrum]]
* Use the elevator between the first and second floor
## Unwritten Rules
* You can avoid triggering this by only using the stairs between the first and second floor
* Elevator will be stuck until using the reset lever in the [[Wickford Basement]]
## Solution
* Turn around and look up
* Exit to the top of the elevator
- Use the box on the right facing the elevator exit 
- Pull yourself up to the [[Wickford Second Floor]]
