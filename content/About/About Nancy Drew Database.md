Hi, I'm the data organizer of the Nancy Drew Database. This overambitious project came from my desire to see how all the puzzles in Nancy Drew worked and connected. Which ones were reskins of the same premise? What hints were provided for different puzzles? Soon it ballooned into cataloguing much more of the games, from characters to the utilities of Nancy's phone. 

The first step of my project was to figure out the scope. I wanted to focus on the games between 2000-2015, otherwise known as the Message in a Haunted Mansion to Sea of Darkness. This was for practical reasons: like nostalgia, considering Midnight in Salem a soft reboot, and accessing the games through Steam as I didn't have them all in CD form. I also decided to skip Ransom of the Seven Ships, game 20, because it got discontinued and I didn't like it that much. There was already going to be some games I've only played a couple times in the mix, no need to force myself when its not available for purchase. 

The second step was figuring out where the data was going to live. My first attempt was through Notion, which conveniently organized much of its data through databases. I was able to classify all the types of time that passes in each game, identify who got the most letters from Nancy (not George), and identify most of the locations and environments in the games. 

But as I got into the details of each game, I found myself getting distracted with making everything look aesthetic. Notion offered the ability to make every page have a cover image, an icon for each page, and I was certain to use that feature to the fullest. It came to the point where I had thousands of screenshots to sift through. It really took away from my main goal, although it did look very nice, it also got to be too much. After finishing a couple games this way, I had to take a break as it wasn't as fun anymore.

That's when I switched to Obsidian. It would also allow me to easily publish to the web using quartz. Since I'm a Software Engineer by day (shout out to Haunted Carousel for my first light hacking), I was able to make the web page look and function just the way I wanted. I got to reuse the existing data I collected and transfer it over, with better connections in between, but without any images. At least for now. 

I only have data for the first few games so far. I have recognized if I'm doing this by myself, this is a multi-year project I've created. But it's allowed me already to get really proficient in multiple new not taking apps, see the game design connecting different items and puzzles, and deep dive into references in the game itself. So far, I've become obsessed with Alphonse Mucha, have way too much knowledge on how certain puzzles came about, and am inspired to make a physical scrapbook of each game like Nancy does. 

Most of all, if you are still reading, thank you to the entire Nancy Drew community (aka the Clue Crew). I'm so happy that these games are still holding a special place in people's hearts and hope that my contribution can be helpful to anyone wanting to see how different puzzles link together while avoiding major spoilers for those who like more of the [[Universal Hint System|UHS]] system (my personal favorite guide). I'll be trying to include as many of the users and websites that I find as part of the references. I'm only one person, so reach out if anything is wrong or can be added at nancydrewdatabase@gmail.com.
