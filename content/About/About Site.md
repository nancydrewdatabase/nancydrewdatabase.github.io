## How to Use

This site began with the simple question. "Why can't I search for every Nancy Drew Puzzle?" Then I began seeing connections - different ways to connect locations, puzzles, second chances, and more.

How to use this site - search for any specific aspect of the game and it should be there! Assuming I've gotten to that game. Stuck on a certain puzzle, find the prerequisites on what you need to complete first. Want to see how many books are in a specific game, there's that too. Want an out of game checklist of things to do? You can use that as well.

This can also be a way for others to expand on my work for their own data reasons. Don't agree with my definition of a puzzle? Go ahead and tweak for your own purpose. Want to compare how Nancy can die in each game? Or how many books there are to read? I don't know what will spark your interest, but you can use this site as a reference for that as well. Everything is free and open source here. All sites I link to will also be free (unless otherwise stated) with additional puzzles and learnings.

What I really enjoy is finding the connections between the games and learning more about different aspects the games touch on. One day I'm deep diving in Maya Glyphs and the next I am obsessively learning nonogram techniques or brushing up on music theory. 

## How it Works

I've explained at a high level in [[History of Nancy Drew Database]], but this database is created entirely in Markdown style. The editor I'm using is called [Obsidian](https://community.obsidian.md/), which is where I do all my writing. 

I have templates I made for all the different types of pages (puzzles, library, environment) to simplify some of the boilerplate details using [Templater](https://community.obsidian.md/plugins/templater-obsidian) extension. It really helps in making sure the pages are consistent. 

I also use [Dataview](https://community.obsidian.md/plugins/dataview) and [Dataview Serializer](https://community.obsidian.md/plugins/dataview-serializer) to make most of my tables for showcasing specific files based on tags. So that's how I collect just Nancy's letters in the Library section for instance. It uses a bit of code for searching and creating a specific table to not manually copy and paste all the different files and automatically update when new files are added.

One thing I wanted to ensure about this site is it would be free. I created a github account and use github pages to host. I use [Quartz](https://quartz.jzhao.xyz/) for publishing to this github page which gave a basic template for the website. As you can probably see, I kept a lot of the basic form, though I do plan on making other customizations in the future.
