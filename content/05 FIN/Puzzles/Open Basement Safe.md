## Prerequisites
* [[Open Basement Trapdoor]]
## Clues
* Find the symbol that appears in all locations
- It’s the spades ♠️ (same suit as [[Beat the Magician - Amazing Monte]])
## Unwritten Rules
* Blocks listed from left to right, 1 to 5
### Junior
* Block 1 moves Block 1 and Block 2
- Block 2 moves Block 2 and Block 3
- Block 3 moves Block 3 and Block 5
- Block 4 moves Block 1 and Block 4
- Block 5 moves only Block 5
### Senior
* Block 1 moves Block 1 and Block 2
- Block 2 moves Block 2 and Block 3
- Block 3 moves Block 3 and Block 5
- Block 4 moves Block 1, Block 4, and Block 3
- Block 5 moves only Block 5
## Solution
* Click each Block until it shows a spade ♠️
- 4, 1, 2, 3, 5

Solution 2
- Turn block four to a clover
- Then turn block one to a diamond
- Turn block two so it is a spade, then turn block three so it is a clover
- Then turn block four to switch blocks one, three and four to spades, and finally, switch block five until it's a spade.[^1]
